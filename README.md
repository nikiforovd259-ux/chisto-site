# Чисто — учебный сайт клининговой компании

Проект создан на основе твоего первого `index.html`: теперь есть содержание,
оформление, адаптация под телефон, калькулятор и демонстрационная форма.
Бренд, тарифы и интерьер — примеры для портфолио. Клиентские заказы и отзывы
не выдумывались. Форма не отправляет данные и не бронирует реальную уборку.

## Как открыть в Windows и VS Code

1. Распакуй ZIP в отдельную папку, например `chisto-site`.
2. В VS Code выбери «Файл → Открыть папку» и укажи `chisto-site`.
3. В проводнике Windows дважды щёлкни по `index.html` — откроется браузер.
4. Меняй файлы в VS Code, сохраняй Ctrl+S, обновляй страницу браузера Ctrl+R.

Никакая установка Node.js или сервера для локального просмотра не нужна.
Не переноси только HTML: стили, скрипты и папка assets должны остаться рядом.

## Какие файлы за что отвечают

| Файл | Назначение |
|---|---|
| index.html | Заголовки, тексты, услуги, поля калькулятора, форма |
| styles.css | Цвета, шрифты, отступы, сетки, адаптация под ширину экрана |
| calculator.js | Тарифы, минимальная стоимость, формула расчёта |
| script.js | Изменение расчёта, меню, окно заявки и скачивание текста |
| assets/clean-home.webp | Изображение для главного экрана |
| original-index.html | Твой исходный файл, сохранённый для сравнения |

## Как считается цена

Базовая уборка = максимум из (площадь × тариф) и минимальной цены формата.
Затем прибавляются: окна × 500 ₽, санузлы сверх первого × 700 ₽ и выбранные
дополнительные услуги. Например, поддерживающая уборка 60 м² = 5 400 ₽.
Генеральная уборка 60 м² + 2 окна + духовка + второй санузел = 11 900 ₽.

## Первые упражнения

1. В index.html найди главный заголовок и измени его. Сохрани и обнови страницу.
2. В styles.css измени --green в :root и посмотри, какие элементы поменяли цвет.
3. В calculator.js измени rate у regular. Одновременно обнови цену в карточке
   услуги в HTML — тексты карточек не связаны с тарифами автоматически.
4. Проверь площадь 20 и 250 м², дополнительные услуги, окно заявки и узкое окно.

## Что потребуется для реальной компании

Подставить подтверждённые тарифы, условия, контакты и реальные фотографии;
подключить обработчик отправки заявок в выбранный канал. Сейчас форма служит
только для демонстрации и создаёт текстовый файл по нажатию пользователя.

## Изображение

Интерьер создан встроенным ImageGen. Краткий запрос: «Photorealistic, spotless
contemporary apartment living room: cream sofa, pale oak table and floor,
white sheer curtains, sage accent wall, indoor plant, natural morning light;
no people, text, branding or watermark; horizontal website hero photograph».
Финальное изображение находится в assets/clean-home.webp. Подробный запрос —
в ASSET_PROMPT.txt.

## Проверка

Проверены синтаксис JavaScript, расчёт цены, минимумы, дополнительные услуги,
недопустимые входные значения и целостность локальных ссылок. Автоматическая
проверка отображения в браузере в этой среде недоступна; посмотри сайт на своём
компьютере и отправь скриншот, если заметишь проблему.
